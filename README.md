# Robotrain 🤖🚀

Robotrain is an **embodied AI training platform** for managing training workflows, experiments, and results in one system.

It combines:
- 🖥️ a web frontend for visualization and management,
- ⚙️ a backend service for orchestration,
- 🧠 a training module for embodied AI / robot learning experiments.

## Features ✨

- 📊 Monitor training progress and experiment results
- 🧩 Manage training tasks in a more structured way
- 🗂️ Organize datasets, models, and logs
- 🔧 Support modular development with frontend, backend, and training components
- 🐳 Run the platform with Docker-based deployment

## Project Structure 📁

- `frontend/` — web interface for interaction and visualization
- `backend/` — backend services and APIs
- `train/` — training pipeline and learning-related code

## Tech Stack 🛠️

- **Frontend:** React, Vite, Redux, Ant Design, ECharts
- **Backend:** Python-based service
- **Training:** Python / embodied AI training pipeline
- **Deployment:** Docker Compose

## Purpose 🎯

This project is built for experimenting with **embodied AI systems** and making training workflows easier to manage, reproduce, and extend.
